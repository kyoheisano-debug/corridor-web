## フェーズ別ロードマップ

### フェーズ0: 需要検証（〜1ヶ月）★現在地の次
**目的: 一番安く「日本人がこのアニメショートに反応するか」を確かめる。アプリも管理ウェブもまだ作らない。**
- [ ] 題材を2〜3本選定（各国の歴史 or オリジナル小説。権利クリアなもの）
- [ ] キャラ設計を先に固定 → **Seedance でパイロット1〜2話**をフル生成 + 人手で編集・音声
- [ ] 制作の**実コスト・日数・到達品質・キャラ一貫性を実測**（量産単価が成立するかの判定材料）
- [ ] TikTok / Instagram Reels に投稿し、再生・保存・コメント・「続き希望」を計測
- [ ] 権利方針のドラフト（論点②）

**フェーズ0の合否KPI（例・要合意）**: 1話の制作コスト/日数が量産可能なライン内 ＆ SNSの保存率・続き希望が基準値超え

### フェーズ1: 課金検証（1〜2ヶ月）
**目的: 「無料数話→課金」の転換率を、アプリを作らずに測る。**
- [ ] LP + 簡易決済（Web課金 / サブスク基盤）で課金導線を仮設
- [ ] 無料話数・課金の刻みをA/Bで検証（論点②）
- [ ] CAC（SNS集客単価）と初期LTVの概算
- [ ] 量産パイプライン（制作フロー・外注/AIツール選定）の設計

### フェーズ2: 基盤構築
**目的: 検証が取れてから本格投資する。**
- [ ] ①視聴者アプリ（iOS/Android）— コイン/ペイウォール/リワード広告
- [ ] ②管理ウェブ（本リポジトリ）— コンテンツ管理・課金・ユーザー/分析
- [ ] 課金基盤（IAP 30%手数料 vs Web課金の方針確定）

### フェーズ3: 量産と組織化
- [ ] 会社設立・チーム分割（制作 / 開発 / マーケ / コーポレート）
- [ ] 制作パイプラインの量産化（目標本数・単価の確定）
- [ ] 資金調達（先行者は5億円規模。ランウェイ設計）

## 主要リスク（市場調査からの要約）

- **先行者リスク**: FLASH（5億円調達済）は隣接プレイヤーだが主軸は実写ドラマ＋モーションコミック。本構想の「フル生成アニメ×オリジナル題材」とは棲み分け可能。ただしアプリ/課金/SNSのノウハウは先行。
- **品質リスク**: Seedance のキャラ一貫性・低コストで量産とコストの矛盾は緩和。ただし**到達するアニメ品質が日本ユーザーの目に耐えるか**はフェーズ0で実測が必要。
- **ツール依存リスク**: 制作を Seedance に依存。API の提供形態・価格改定・規約（商用利用/著作権）変更に備え、代替モデルも評価しておく。
- **集客コスト**: ReelShort も赤字。マーケ費が利益を食う構造。CAC<LTV を厳格に管理。
- **権利**: 小説アニメ化は翻案権の許諾必須。歴史×オリジナルで内製化するのが安全。
- **プラットフォーム手数料**: IAP 30%。Web課金回避の是非を早期に判断。
