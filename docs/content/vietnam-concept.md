# 第1作 企画: ベトナム史シリーズ（コンセプト案）

> 作成: 2026-06-20 / ステータス: 企画ドラフト（フラッグシップ題材の決定待ち）
> 方針: ベトナム史の「面白い部分」をAIで小説化 → Seedanceでショートアニメ化。
> 主人公＋ヒロイン＋仲間の構成。**史実ベース＋デフォルメ**で、戦い・恋愛を面白おかしく。

---

## 0. なぜベトナム史か（戦略的な裏付け）

- **競合がいない題材**: アニメ化された日本の作品で「ベトナム史」を主軸にしたものはほぼ皆無 → 強い差別化。
- **物語の鉱脈が濃い**: 中国・モンゴル・明という超大国に、小国ベトナムが何度も勝つ「**判官びいき（underdog）**」構造。
  ショートアニメの「引き」と相性が良い。
- **将来の市場拡張**: ベトナムは人口約1億・若年層が厚い。**ベトナム市場への横展開**が将来狙える
  （Seedanceは多言語リップシンク対応＝ベトナム語版も作りやすい）。
- **⚠️ 留意点**: ベトナムでは英雄（特に陳興道は「徳聖陳」として神格化）への敬意が強い。**実在の国民的英雄は
  尊重して描き、デフォルメ（コメディ・恋愛・脚色）は架空キャラや仲間に厚く乗せる**のが安全。各国版展開時の炎上回避。

---

## 1. 制作の基本方針（史実 × デフォルメ）

| 守る（史実ベース） | 盛る（デフォルメ） |
|---|---|
| 時代・主要事件・実在の英雄の功績・象徴的な戦術 | **架空のヒロイン**を1人立てて恋愛軸を作る |
| 名場面（オレンジを握り潰す/杭の戦い 等） | 仲間に立ったキャラ付け（特技・口癖・コメディ） |
| 「超大国 vs 小国」の構図と勝利の爽快感 | タイムラインの圧縮、ライバル関係の強調 |
| 国民的英雄への敬意 | 戦いの派手な演出、青春・友情・ギャグの軽さ |

- **小説化はAIで**: 史実の骨子を渡し、AIでエピソード単位のプロット→脚本（縦型ショート用の短い尺）に展開。
- **尺**: 1話60〜90秒、毎話クリフハンガー。第1〜数話無料 → 課金。

## 2. フラッグシップ題材の候補

### ★案A（推奨）: 陳朝 × モンゴル撃退 ―「殺韃（サッタツ）」
**世界最強モンゴル帝国の3度の侵攻を、小国・大越が撃退した史実。少年主人公の王道成長譚に最適。**

- **時代**: 13世紀・陳朝。フビライ＝ハンのモンゴル帝国が3度（1258 / 1285 / 1287-88）侵攻 → すべて撃退。
- **主人公（史実）**: **陳国瓚（チャン・クォック・トアン / Trần Quốc Toản）**。当時16歳の少年貴族。
  軍議に「若すぎる」と参加を許されず、悔しさのあまり**手にしたミカンを握り潰したことに気づかなかった**という逸話。
  その後「**破強敵・報皇恩**」の旗を掲げ千人の私兵を集め参戦。**＝少年漫画的な主人公として完璧**。
- **司令官（史実）**: **陳興道（チャン・フン・ダオ）**。天才軍師。檄文で兵を鼓舞。※神格化されており敬意をもって描く。
- **仲間（史実）**:
  - **イェッ・キエウ（Yết Kiêu）**: 潜水の達人。敵船底に穴を開けて沈める“水のスペシャリスト”。
  - **ファム・グー・ラオ（Phạm Ngũ Lão）**: 籠を編むのに夢中で足に槍が刺さっても気づかなかった豪傑。
- **ヒロイン（架空）**: 主人公と身分違い／敵味方の機微を絡めた恋愛軸を新規創作。
- **名場面（史実＝映像映え）**:
  - 焦土作戦「**家を空にし庭を空にする**」で敵を消耗させる
  - 兵が腕に「**殺韃（タタールを殺す）**」と刺青して士気を示す
  - 老臣を集めた**ディエン・ホン会議**で全員が「戦う！」と叫ぶ
  - クライマックス: **バクダン江の戦い（1288）**。川底に鉄杭を仕込み、満潮で敵艦隊を誘い込み干潮で座礁・殲滅。
- **シーズン構成**: 3度の侵攻＝3部構成に自然に分割できる（連載・課金設計と好相性）。

### 案B: 徴姉妹（チュン・シスターズ）の反乱 ― 女性主人公の悲劇英雄譚
- **時代**: 西暦40年。中国・後漢の支配に対し、**徴側（チュン・チャク）・徴弐（チュン・ニ）姉妹**が蜂起。
- **恋愛軸が史実に内蔵**: 姉チャクの夫**詩索（ティ・サック）**を漢の太守に処刑されたことが蜂起の引き金。
- **仲間**: 伝説では**80人以上の女性将軍**が集結。象に乗って戦う。
- **構図**: 一時独立を勝ち取るも、馬援の大軍に敗れ悲劇的結末（川に身を投じる伝承）。**女性ダブル主人公**で
  他社と差別化が際立つ。ややビター。
- ※近接題材として**趙嫗（バ・チエウ / 248年）**「私は嵐に乗りクジラを斬りたい」も女性英雄もの。

### 案C: 黎利と神剣 ― 明への抵抗＋神剣ファンタジー
- **時代**: 15世紀。**黎利（レ・ロイ）**が明の支配に対しラムソンで蜂起。軍師**阮廌（グエン・チャイ）**。
- **フック**: 湖の神亀から授かった**神剣**で明を破り、勝利後に亀へ剣を返す（ホアンキエム湖伝説）。
  **神剣ファンタジー要素**がアニメと好相性。主人公＋軍師＋（架空）ヒロインの座組み。

> **推奨は案A。** 少年主人公の王道成長譚／最強モンゴル相手の最大級の爽快感／個性的な仲間が史実に揃う／
> 3侵攻でシーズン分割できる、と縦型ショートアニメの要件に最も合致。
> 案B（女性主人公）も差別化が鋭く、A の次の第2シリーズ候補として有力。

## 4. フェーズ0 パイロットの具体案（最初に作るもの）

**目的: Seedanceで「ベトナム史×アニメ品質×縦型」が成立するかをSNSで実測する。**

1. **パイロット第1話「握り潰したミカン」（約60〜90秒）**
   - 軍議から締め出される → 悔しさでミカンを握り潰す → 「破強敵・報皇恩」の旗を掲げ決意、で引く。
   - キャラ立て＋世界観＋クリフハンガーを1本に凝縮。主人公のフックが強い。
2. **（任意）バトル予告カット（15〜30秒）**: バクダン江の杭の戦いの“画ヂカラ”でスタイルを提示。

- **実測KPI**（roadmap フェーズ0 と連動）: 1話あたり実コスト・制作日数・到達品質・キャラ一貫性、
  およびSNSの再生/保存/「続き希望」コメント率。
