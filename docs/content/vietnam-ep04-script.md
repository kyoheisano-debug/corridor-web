# 第4話 脚本「殺韃の誓い」

> 作成: 2026-06-20 / シリーズ: 陳朝×モンゴル撃退編 / 尺: 約82秒（縦型 9:16）
> 方針: 戦い重視。マイ奪還で恋愛軸を前進、豪傑ファム・グー・ラオ獲得、「殺韃」で結束。
> 無料区間の感情ピーク手前。ラストは反攻の秘策＋強敵の将の影で引く。
> キャラ設定は [`character-design.md`](./character-design.md) / 全体構成は [`vietnam-season1-arc.md`](./vietnam-season1-arc.md)。

## ログライン
マイを追うトアンの前に立ちはだかる敵を、豪傑ファム・グー・ラオが一蹴する。仲間とともに
夜襲でマイを奪還したトアンは、腕に「殺韃」と刻み結束を誓う。だが反攻の秘策の先に、
モンゴルの名将・唆都（サド）の影が迫る――。

- **ナレーション**: 「腕に刻むは『殺韃』の二文字。退かぬという、血の誓い。」
