# 第2話 脚本「初陣」

> 作成: 2026-06-20 / シリーズ: 陳朝×モンゴル撃退編 / 尺: 約80秒（縦型 9:16）
> 方針: 戦い重視。初陣の爽快感→現実の壁→仲間（イェッ・キエウ）獲得→撤退命令の引き。
> キャラ設定は [`character-design.md`](./character-design.md) / 全体構成は [`vietnam-season1-arc.md`](./vietnam-season1-arc.md)。

## ログライン
勇んで初陣に臨んだトアンは敵の手練れに圧倒され死地に陥る。だが川から現れた潜水の達人
イェッ・キエウに救われ、「気持ちだけでは勝てない」現実を知る――そこへ脱歓の本隊が迫る。

- **映像**: 歴戦のモンゴル将がトアンを狙う。剣を弾かれ、馬蹄に転がされ、地に伏す。
- **ナレーション**: 「だが戦場は、勢いだけの少年に容赦しなかった。」
- **Seedance**:

### S4 ｜ 31–43s ｜ イェッ・キエウ登場（仲間獲得）

- **映像**: イェッ・キエウが水路に潜り、モンゴルの渡河船の底を裂いて沈める。トアン、目を見張る。
- **トアン**: 「すげぇ……あれが、戦い方……。」
- **Seedance**:

### S6 ｜ 54–64s ｜ 手当てと自覚（恋愛の絡み）

- **Seedance**:
```

```

- **映像**: 地平線が黒く埋まる——脱歓率いるモンゴル本隊。退却の角笛が鳴り響く。
- **ナレーション**: 「脱歓の本隊、二十万。退却の角笛が、戦場を裂いた。」
- **Seedance**:
```

banners, a retreat horn echoing, soldiers turning to fall back, overwhelming
```

- **陳興道（影・声のみ）**: 「退いて、勝つ。それが戦だ。」 / **テロップ**: 「――次回、焦土。」
- **Seedance**:
```

```
