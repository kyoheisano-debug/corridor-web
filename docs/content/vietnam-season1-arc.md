# シーズン1 全体構成（陳朝×モンゴル編 / 第2次侵攻 1285）

> 作成: 2026-06-20 / 対象: 第1作シーズン1 / 尺: 各話60〜90秒・毎話クリフハンガー
> 史実の軸: モンゴル第2次侵攻（1285）。脱歓（トゴン）率いる大軍 → 焦土戦術で消耗 →
> 鹹子（ハムトゥ）・章陽（チュオンズオン）の反攻 → 昇龍奪還。※史実ベース＋デフォルメ。

---

## 1. 無料→課金の設計思想

- **第1〜4話を無料**で公開し、**第5話の最高潮（反攻の火蓋／ヒロイン危機）でペイウォール**。
- 各話は必ず**クリフハンガー**で終え、次話視聴へ強制力をかける。無料区間は
  「主人公の成長 × 戦いの爽快感 × マイとの関係前進」を積み上げ、第5話で**最大の引き**を作る。
- 課金後（第6話〜）で反攻クライマックス〜昇龍奪還まで一気に解放し、満足度で継続課金へ。

> 課金の刻み・コイン設計は別途 `docs/roadmap.md` の課金UX論点で詰める。本書は物語の流れに集中。

## 3. 各話の役割（無料区間の設計）

- **第1話**: 主人公・世界観・脅威・動機を提示（済）。掴み＝ミカン。
- **第2話**: 「気持ちだけでは勝てない」を体感させ、仲間（イェッ・キエウ）を得る。戦いの爽快感も入れる。
- **第3話**: 師（陳興道）と戦略を提示。退却＝敗北ではないという物語の芯。マイの危機で感情を引っ張る。
- **第4話**: マイ奪還で恋愛軸を前進＋「殺韃」で結束。主人公が一人前に近づく。無料区間の感情ピーク手前。
- **第5話（課金境界）**: 反攻開始の高揚を最大化し、**斬り込みの瞬間で暗転**。「この先が見たい」を最大化。

## 5. 制作メモ
- 各話の脚本は `vietnam-epNN-script.md`、構造化スペックは `pipeline/episodes/epNN.json`。
- 新キャラ登場話の前に `pipeline/characters.json` の参照プロンプトを確定しておく。
- 史実の英雄（陳興道）は敬意をもって描写。デフォルメ・恋愛・ギャグは架空キャラ（マイ）と仲間に寄せる。
